# Decentralized Principal Component Analysis

This repository contains the work developed during my **international internship at Okayama University, Japan**, under the supervision of **Professor Norikazu Takahashi**.

## Project Overview

The project focuses on **Decentralized Principal Component Analysis (DPCA)** in a **Multi-Agent System (MAS)**.

The objective is to allow multiple agents to collaboratively compute the principal components of a global dataset while keeping their local data private. The project investigates distributed averaging, iterative PCA methods, consensus mechanisms, and the influence of network topology on convergence.
